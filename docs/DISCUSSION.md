# 模型之間的討論:標準格式

兩個模型(或同模型兩個 session)要一起得出結論時,用這個格式。**沒有紀錄的討論等於沒發生**——結論會被引用,過程要能被翻出來看。

## 什麼時候用
| 情境 | 兩方 | 目的 |
|---|---|---|
| 模型私有記憶超過上限(D-006) | 高階模型(老師)× 該模型(學生) | 決定壓縮還是打破上限 |
| 複雜規劃 | 兩個高階模型各自規劃後比較 | 找出分歧,選一個或合併 |
| 外部模型的審稿(agy / Codex) | 主線 × 外部模型 | 讓它挑戰,不是讓它按讚 |
| 票面與實作者衝突 | 派工者 × 實作者 | 「票寫錯了」的裁決 |

## 檔案
`discussions/<date>-<topic>.md`(agent-control 或專案的 `docs/discussions/`),用 `templates/discussion.md`。記憶整理的討論檔路徑要寫進該記憶檔 `cap_history` 那一列的 `discussion:` 欄。

## 每一輪必填(兩方都一樣,沒有例外)
| 欄 | 內容 |
|---|---|
| **主張** | 一句話,可被反駁的形狀 |
| **證據等級** | `實測(指令 / 輸出)` / `讀 code 推的` / `引用(裁示或文件)` / `經驗(來自記憶第幾條)` —— 四選一,不准混寫 |
| **什麼會讓我改變主意** | 具體到對方做得出來的事(「如果你量出 X < 3.0 我就同意」) |
| **對上一輪的回應** | 逐點:同意 / 反對 + 理由 / 需要補證據 |

## 停止條件(先寫在檔頭,討論中不准改)
- 雙方同意;或
- 連續一輪沒有新證據,只剩立場;或
- 輪數上限(預設 3,老師帶學生可到 5);或
- 預算上限(token 或時間,寫數字)。
停下來的時候還有分歧,**分歧保留,不硬合**,交主線或人裁。

## 結論區(必填)
- **結論**:一句話。
- **採用的證據**:哪幾條實測支撐它(讀 code 推的不能單獨支撐結論)。
- **保留的分歧**:誰、主張什麼、為什麼沒被說服。
- **產出**:記憶新版 / 上限變更(from → to,理由)/ 裁示草案 / 票。
- **這次討論教了誰什麼**:每一方一行,寫回自己的模型記憶(這就是「學生成長」那一格)。

## 老師帶學生(記憶整理)的額外規矩
- 老師**不替學生刪**;老師問「這條你下次還會用到嗎?為什麼?」,學生答,答不出來的才降級。
- 學生可以**主張打破上限**,但要拿出「多讀這幾百字替每個未來 session 省了什麼」;老師只判理由站不站得住。
- 反例與盲點優先於成功經驗;三個標記(日期、來源、實測/推論)壓縮不能壓掉。
- 討論檔就是 `memory.py consolidate --discussion <path>` 的必要輸入;沒有討論檔的整理拒絕執行。兩個模型**各一份**,兩份都要給(`--discussion A --discussion B`)。

### 記憶整理討論檔的檔頭與逐條處置(#76)
檔頭三行(放 front matter 或正文開頭都可以;後兩行照 `python3 scripts/memory.py snapshot <主檔>` 的輸出抄,兩份必須一樣):
```
model: <你的模型>
source_lines: <K>
source_sha256: <inbox 前 K 行的 sha256>
```
`## 結論` 區對 inbox 的第 1..K 行**每一行**寫一句處置,其後可接目的地:
```
- L1: 保留
- L2: 升格 memory/role/worker.md
- L3: 移至 reference docs/…
- L4: 歸檔
- L5: 重複 L2
```
處置只有五種:`保留`、`升格`、`移至 reference`、`歸檔`、`重複`。缺任一行,`consolidate` 拒絕 —— 沒處置過的那一行不會被消耗,K 之後新記的也不會。
