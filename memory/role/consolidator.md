# Role memory: consolidator

Principles learned while doing this role. Rules for the job are in the prompt; this holds what experience added.

- A lesson earns a line when it recurred (two tickets or more) or came from one costly failure, and an agent can act on it from the task in front of it. A one-off story stays in its ticket.
- Prune on every pass: drop lines the prompt or the code now enforce, lines about tools or steps the loop no longer has, and merge near-duplicates. A memory file that only grows taxes every session that reads it.
